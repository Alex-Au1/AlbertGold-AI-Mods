# AlbertGold AI Mods

Mods for 3DMigoto-based loaders whose meshes and textures are generated by code written by Claude agents, with
no 3D editor involved. An experiment.

| Mod | Character | Preview |
| --- | --- | --- |
| [EiBlossomPrincess](Mods/GI/Ei/EiBlossomPrincess/Ei) | Raiden Shogun (Genshin Impact) | [sheet](Docs/Previews/EiBlossomPrincess.png) |

Each mod is produced by its recipe under `Tools/Builders/`, on top of the small toolkit in `Tools/ModKit`.
See [`CLAUDE.md`](CLAUDE.md) and [`AI Agent Help/`](AI%20Agent%20Help/README.md).

`EiBlossomPrincess` is a fan-made outfit inspired by Terra's "Blossom Princess" style in Dissidia Duellum Final
Fantasy; all geometry and textures are made from Raiden's own model and procedural painting, nothing is taken
from that game.
