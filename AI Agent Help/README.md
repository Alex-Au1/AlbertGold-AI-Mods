# AI Agent Help

Operating notes for agents working in this repo, one folder per topic. Start from the table in the root
[`CLAUDE.md`](../CLAUDE.md).

- [Overview](Overview/CLAUDE.md): layout, sources, what is generated
- [Mod Building](ModBuilding/CLAUDE.md): the toolkit, the working loop, model facts and traps
- [Outfit Transfer](OutfitTransfer/CLAUDE.md): an outfit from an outside model (.fbx) fitted to a character; Mavuika's model, measured
- [Skill Objects](SkillObjects/CLAUDE.md): a thing a character summons (Mavuika's bike as the Fenrir), from an outside `.stl`
- [Weapons](Weapons/CLAUDE.md): a character's weapon (Mavuika's claymore as the Fusion Sword), dumped from the game, from an outside textured `.dae`
- Private (only in the private repo `AlbertGold-Private-AI-Mods`): mods that are not public, see `Private/README.md` there
